# Rise & Arcade 기록지

Pump It Up **Rise** / **Arcade** 개인 점수 기록을 관리하는 웹앱입니다.
브라우저에 자동 저장되지 않고, JSON 백업 파일로 직접 저장/불러오기 하는 방식입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 마크업 (게임 선택, 곡 목록, 각종 모달 등) |
| `style.css` | 전체 스타일 |
| `app.js` | 앱 로직 (곡 데이터, 기록 관리, 랭크/랭킹 계산, 백업 등) |
| `rise_arcade_backup.json` | 예시 백업 파일 (곡 목록 + 기록 데이터) |

## 실행 방법

별도 서버나 빌드 과정 없이, `index.html`을 브라우저로 열면 바로 동작합니다.

```bash
open index.html   # 또는 더블클릭
```

## 주요 기능

### 기록 관리
- Rise / Arcade 게임 전환, 싱글·더블(또는 하프더블) 모드, 레벨별 곡 목록
- 곡별 점수 입력 → 게임/모드별 랭크 자동 표시
  - Rise: S / SS / SSS / 100만점(무지개)
  - Arcade: A ~ SSS+ (동/은/금/다이아/무지개), Plate(PG~RG) 판정 선택
- 곡 검색, 100만점(올퍼) 제외 보기, 랜덤 곡 뽑기(전체 / 올퍼 제외 / 미등록)
- 🔥 올퍼 근접곡 보기 (거의 만점에 가까운 곡 모아보기)
- 📊 통계 (레벨별 클리어 현황 그래프)

### 곡 관리
- `+ 곡 등록`으로 신규 곡 등록 (제목 + 게임/모드별 레벨 + 이미지)
- 곡 검색 후 수정 / 삭제

### 🏆 Phoenix Pump Ability
- Arcade 기록만 대상으로 계산 (Rise 제외)
- 곡별 Pump Ability = `((레벨 + 27 또는 26) × (G - P - 235)) / 100`
  - G: 점수 기반 랭크 점수 (AA 미만은 계산 제외)
  - P: 클리어 판정(Plate) 점수 (판정 미지정 시 계산 제외)
- **Single / Double Pump Ability**: 각 모드별 상위 50곡 합산
- **Total Pump Ability**: 싱글+더블 전체 곡을 합친 풀에서 Pump Ability 상위 50곡만 뽑아 합산 (Single + Double을 단순히 더한 값이 아님)
- 패널 내 `싱글 / 더블 / 전체` 탭으로 각 Top 50 목록을 나눠서 확인 가능

### 🎖 칭호
- Single / Double / Total Pump Ability 기준으로 등급별 칭호 해금
  - 등급 색상(텍스트): 동 → 은 → 금 → 연한 다이아 → 진한 다이아 → 루비 → 자수정 → 무지개
- 최초 달성 시에만 1회 토스트 알림 (재알림 없음, 백업 불러오기 시에도 조용히 반영되어 중복 알림 방지)
- 보유한 칭호 중 하나를 대표 칭호로 자유롭게 선택 가능

### 프로필 (왼쪽 상단)
- 원형 배지: Total Pump Ability 수치를 표시하고, 현재 도달한 Total 칭호 등급 색으로 채워짐
- 대표 칭호 / 이름 표시 (이름은 클릭해서 직접 입력)

### 백업 / 불러오기
- `백업` 버튼: 곡 데이터, 기록, 칭호 진행 상황(해금 목록 + 대표 칭호), 이름, Pump Ability 스냅샷을 JSON으로 내보내기
- `불러오기` 버튼: 위 JSON 파일을 다시 불러와 복원
- ⚠️ 브라우저에 자동 저장되지 않으므로, 새로고침 전에 반드시 백업 후 다음 세션에서 불러오기 필요

### 개발자 패널
- 게임 타이틀을 5번 클릭하면 열림
- 이미지/개인 점수를 제외한 배포용 곡 목록만 내보내기
- 전체 점수 기록 초기화 (곡 목록/난이도는 유지, 확인 문구 입력 필요)

## 데이터 구조 (백업 JSON)

```jsonc
{
  "songData": { "rise": { "single": {...}, "double": {...} }, "arcade": {...} },
  "userRecords": { "rise": {...}, "arcade": {...} },
  "titleProgress": { "unlocked": ["..."], "selected": "..." },
  "profile": { "name": "..." },
  "phoenixPumpAbility": {
    "singlePumpAbility": 0,
    "doublePumpAbility": 0,
    "totalPumpAbility": 0
  }
}
```
